## Le site

- **[Exemples](#service-client)** : pour chaque cas d'usage, une page de présentation (besoin, fonctionnement, schéma des composants, lancement, évaluation, limites) et une page « Comment ça marche ? », le texte affiché dans l'application.
- **[Architecture](#vue-d-ensemble)** : principes, briques techniques, et les modules partagés par tous les exemples : garde, LLMOps, socle.
- **[Utiliser](#installation)** : installation, modèles par défaut, GPU plus petit, tests et résultats mesurés.
- **[Lexique](#lexique)** : les sigles et les noms d'outils cités.

Le code est sur GitHub : [github.com/xavinsky/exemplia](https://github.com/xavinsky/exemplia). Ces pages sont tirées directement de sa documentation.
