Garde d'entrée et de sortie

Chaque contrôle rend un verdict : autoriser, modifier (données masquées) ou bloquer. La chaîne s'arrête au premier blocage. Les contrôles à base de modèle (modération, juge) ne sont appelés que si la case est cochée.

Sur cette page, vous écrivez à la place de l'assistant. En production, la chaîne est : le client pose une question → le code rassemble les sources (documents, résultats d'outils) → l'assistant rédige sa réponse → la garde contrôle cette réponse avant de l'envoyer. En sens « sortie », le texte à contrôler est donc la réponse de l'assistant, et le contexte reconstitue ce qu'il avait sous les yeux pour la produire.

Texte à contrôler

Choisissez d'abord ce que vous contrôlez : un message qui entre, avant qu'il n'atteigne le modèle, ou une réponse qui sort, avant qu'elle n'atteigne le client. Les champs suivent, dans l'ordre chronologique de la conversation.
