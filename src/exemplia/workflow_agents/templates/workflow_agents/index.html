Workflow d'agents

Un email entrant est traité de bout en bout, jusqu'à un brouillon validé par un conseiller. Workflow : étapes fixées par le code (classer, extraire, vérifier, rédiger). Orchestrateur : un superviseur choisit quels agents spécialisés consulter. Dans les deux cas, le graphe se met en pause pour la validation humaine et aucune action n'est exécutée sans elle.
